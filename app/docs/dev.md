# Developing Alethiometer: devshell, builds, checks, running

Moved out of HANDOFF.md (2026-10-21), unchanged.

- App: `app/` (Tauri 2, Rust core in `app/src-tauri`, Svelte 5 UI in `app/src`).
- **Devshell**: `flake.nix`/`devshell.toml`/`.envrc` at repo root (numtide/devshell, same pattern as `k8s-iac`). `direnv allow` once, then `cargo`/`node`/`pkg-config`/`openssl` resolve inside the repo — nothing installed system-wide. `language.rust` module handles Darwin `*-sys` crate linking (frameworks, `xcbuild` toolchain on PATH). On Linux the devshell links with mold (`CARGO_TARGET_<host>_RUSTFLAGS` in `flake.nix`'s Linux block): a one-file desktop rebuild went from ~22 s to ~7 s with GNU ld out of the loop. Outside the devshell (cloud sessions) the default linker is used.
- **Crates (2026-10-08):** the app is now `app/core`, `app/settings`, `app/platform` and `app/src-tauri`; tests are sibling `tests.rs` files; architecture rules with exact allowlists are in `src-tauri/tests/architecture.rs`; `[profile.dev] debug = "line-tables-only"` took the Mac rebuild from ~5.7 s to ~3.7 s. Read `app/docs/crates.md` (what moved, decisions, what is left: the `&App` users, `agents` first).
- **Build speed (2026-10-08):** `app/src-tauri/.cargo/config.toml` builds the bundled SQLite with `SQLITE_DEFAULT_MEMSTATUS=0`. Its memory-stats mutex serialized every allocation across parallel test threads (unit tests 140 s → 4.4 s on 32 cores). Don't start reading `sqlite3_status`/`soft_heap_limit` without revisiting this. Dependency debuginfo off (`[profile.dev.package."*"] debug = false`) was measured on the Mac: no change to incremental rebuilds; it would still save ~12 s per clean build and ~1.5 GB. Clean-build critical path is `tract-core` → `tract-onnx` → the lib → its test binary.
  - **`npx tauri dev` rebuild (Linux, mold, one-file edit): 6.8 s** = ~1.1 s cargo fingerprinting, 3.6 s the `alethiometer` lib, 2.0 s the binary (mostly link). GNU ld was 23 s in the same clean env. Measure with `cargo build --timings` after appending a comment to a source file.
  - **Remaining options, best first:** (1) dependency debuginfo off, above (~0.5–1 s per rebuild); (2) splitting the 47k-line lib into workspace crates (store/sync/agents/embed) might save 1–2 s of the lib's 3.6 s, a big refactor, skipped; (3) Cranelift backend and the parallel front end need nightly, which the Nix stable toolchain doesn't give us, skipped. UI-only edits never rebuild Rust (Vite HMR).
- Checks: `cargo fmt --check` in `app/src-tauri` and `app/agentd` (rustfmt) and `npm run format:check` in `app` (Prettier with the Svelte plugin), both 120 columns since 2026-10-08 (the reformat commits are in `.git-blame-ignore-revs`), `cd app/src-tauri && cargo test --no-default-features`, and `cargo test` in `app/core`, `app/settings`, `app/platform` (561 tests in all; also `cargo fmt --check` in each), `cd app/agentd && cargo test` (the agent host), `cargo build` (desktop; needs WebKitGTK dev libs on Linux, nothing extra on macOS), `cd app && npx svelte-check --tsconfig ./tsconfig.json`.
- Browser-mode dev: `ALETHIOMETER_FAKE_NOW=10:52 npm run devserver` + `npm run dev` (set `ALETHIOMETER_DATA_DIR` to a temp dir to keep off the real DB); screenshots with `node scripts/shot.mjs out.png <tab> [keys…]` (needs Playwright). Desktop dev: `npx tauri dev`.
  - **Anywhere:** `npm run devserver` builds the Rust core once and doesn't rebuild on Rust changes. Restart it after editing Rust, or the UI talks to the old binary (shows as "unknown command"). `npx tauri dev` (real window, real IPC) rebuilds and relaunches on Rust changes; Vite hot-reloads Svelte either way.
  - **Release build (Mac):** `cd app && npx tauri build --bundles app` → `src-tauri/target/release/bundle/macos/Alethiometer.app`. `signingIdentity` is `"-"` (ad-hoc); there's no Apple Developer identity in the keychain. The built app and `npx tauri dev` share the real data dir by default. The identifier in `tauri.conf.json` doesn't pick it (`state.rs` hardcodes `dev.alethiometer.app`), so to keep dev off it run `ALETHIOMETER_DATA_DIR=~/.alethiometer-dev npx tauri dev`. A copied data dir keeps `obsidian_vault` pointing at the real vault.
  - **On the Mac (devshell):** Playwright isn't in the devshell yet, so `shot.mjs` won't run there.
  - **UI checks:** `scripts/ui-diff.sh <ref>` starts the UI at `ref` and this checkout side by side (fresh sample data, clock at 10:52, two scripted agents, a fake Scion hub), then `node scripts/ui-diff.mjs [scene…]` pixel-diffs ~94 scenes (exact, 0 px tolerance) with before/after shots in `$TMPDIR/alethiometer-ui-diff/<slot>/out/<scene>.{a,b,diff}.png`, and `node scripts/ui-keys.mjs [file…]` runs the behaviour checks in `scripts/ui-keys/*.mjs` (100: Escape, outside clicks, focus, pickers, ⌘ vs Ctrl, split review). Needs Playwright and ImageMagick. `UI_DIFF_SLOT=n` runs a separate copy (own ports and folder) so parallel worktrees can diff at once; `scripts/ui-diff.sh stop` stops a slot and all its shards. `UI_DIFF_SHARDS=n` (default 2) starts n server pairs per slot and `ui-diff.mjs` runs its scenes in n parallel chunks (ports in the `ui-diff.sh` header; shots still in one `out` folder): a full run takes ~3 min with 2 shards (~5 min with 1, ~2 min with 4), plus ~30 s for `ui-diff.sh`. While iterating run only the scenes you touched (`node scripts/ui-diff.mjs scene…`) and a full run once at the end. Scenes and checks write to the sample data, so restart `ui-diff.sh` before a clean run, and the last scenes in `ui-diff.mjs` (`// Done and dismissed`) must stay last (they stay in the last chunk, in order). See `app/docs/ui-plan.md`.
  - **Claude Code cloud sessions:** Playwright is installed globally with Chromium in `/opt/pw-browsers`; `shot.mjs` falls back to the global install. Don't run `playwright install`.
  - **Claude Code's Bash tool (cloud or local):** each command runs as `bash -c "<the whole command>"`, so `pkill -f target/debug/devserver` matches that shell and kills it along with the server. Use `kill $(pgrep -f "[t]arget/debug/devserver")` (the bracket keeps the pattern from matching itself). In your own terminal a plain `pkill -f` is fine.
- Real data dir on the Mac: `~/Library/Application Support/dev.alethiometer.app` (`settings.json`, `secrets.json` mode 0600, `alethiometer.sqlite`). Keychain isn't wired, secrets live in the file.
