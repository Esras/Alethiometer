15A Slack signal the AI split across topics
What the code does today: suggest_topics can break one DM or thread into groups. The group with the newest message stays on the item and the rest become child items (parent_id), each filed under its own topic. In Incoming each piece shows up as an ordinary signal with nothing to say it's part of a larger conversation. In both options below, Confirm and Wrong topic act on this topic's messages only, and triage takes the same number of steps.
15hThe same view as 15g, for a channel with a thread. A thread's replies are indented under the thread's first message, behind a thin rule, which is Slack's own look, so indenting stays reserved for real threads. The AI treats a thread as one unit, so the whole thread lands in one group unless it's clearly split. Top-level channel messages group as they do in a DM. Each speaker's name gets their own colour (L 0.65). New here: d dismisses a message in place (10:40, with u undo). Confirm confirms only the groups that have a topic, so Unsorted (Marco's VPN message) stays in Incoming. j/k skips ⋯. t opens the usual topic picker, where you can also create a topic. The footer wraps to a second line when there are many groups.
