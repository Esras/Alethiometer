26Settings, revised · modal from the cog · live reload · grouped cards
26aA modal, opened from the cog next to the sync status, or with ⌘,. Esc closes it. No restart bar. Saving writes settings.json, then Alethiometer re-reads it and applies the change live, including ui_scale (Tauri can change the webview zoom in place) and source changes (the connector restarts). If a setting ever truly can’t apply live, Alethiometer restarts itself on save and says so in the header. A hand edit to the file is picked up the same way. Readability: each group is its own card with space between them. Descriptions are cut to one short line, or left out where the label says enough. The key path only appears on the focused row. Type sets the interface and monospace faces, picked from installed fonts and each shown in its own face, plus two base sizes: interface and reading text (messages, notes, drafts). Interface scale multiplies both. Keys: ui_font, mono_font, ui_font_size, reading_font_size.

25Settings · ⌘, · one row per settings.json field
25aSettings is a page, not a tab. ⌘, opens it in the content area, as on any Mac app, so ⌘1–⌘6 stay the six tabs. Esc or ⌘, again closes it. On the left are the sections, numbered so 1–6 jump; on the right, one row per field. Each row shows its label, a description taken from the doc comment in settings.rs, and the real key path, so the page and the file explain each other. Most changes apply at once. Ones the app only reads at startup (ui_scale, sources) say on restart and collect in a bar at the bottom. Categories gets its own section with the same editor as the Topics index, which already writes settings.json.

25bSources. The one section that’s a list. Each source shows its kind, tag and freshness, and a red dot on the section marks one that needs attention (GitHub has no token). The detail pane renders fields from the connector’s schema, grouped as identity, secrets, what it reads, and limits. Secrets are write-only: you see that one is set, and when, but never its value. Replace… writes it to the Keychain. Schema gap: Settings is fully typed, but sources[].config is an untyped Value that each connector parses for itself. Building this page means giving each connector a typed config struct (with schemars generating one JSON schema for the whole file). That also gets you validation on hand edits.
